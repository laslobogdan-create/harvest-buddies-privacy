Harvest Buddies

Request Data Deletion

Harvest Buddies uses Firebase Anonymous Authentication and Cloud Firestore to save player nicknames and game progress.

You can request deletion of your stored game data without reinstalling or opening the game.

How to Request Deletion

  1. Send an email to the developer using the button below.
  2. Include your player nickname and, if available, your anonymous player ID.
  3. We may request additional information to verify which game data belongs to you.

Request Data Deletion

What Will Be Deleted?

After verifying the request, we will delete the associated player nickname, saved game progress, and anonymous Firebase Authentication account, subject to any legally required retention.
